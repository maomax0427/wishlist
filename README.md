# ほしい物リスト

商品ページのリンクを貼るだけで、**写真・値段・ショップ名** を自動で取ってきてリストにするアプリ。
値段は6時間ごとに確認して、値下がり・目標価格になったらメールでお知らせします。

- アプリ: https://maomax0427.github.io/wishlist/
- iPhone: Safariで開いて 共有 → ホーム画面に追加

## できること

- **ほしい物** … リンクを貼り付け（または iPhone の共有ボタン）で追加。写真のグリッド、合計金額、カテゴリ別、並べ替え
- **詳細** … 写真を切り替えてメインを選ぶ、値段の動きグラフ、ほしい度（♥1〜3）、カテゴリ（自動で推測）、目標価格、メモ
- **買った** … 「買った！」で移動。年間の合計と、値下がりでおトクになった額
- **設定** … スプレッドシート連携、共有ボタン用ショートカットの作り方、カテゴリ編集、バックアップ

## しくみ

```
商品ページ ──> Apps Script（UrlFetch / r.jina.ai）──> スプレッドシート「ほしい物データ」
                    │  読み取りルールは extract.js を GitHub Pages から読み込む
                    └─ 6時間ごとに値段を確認 → 値下がりしたら Gmail
アプリ（このリポジトリ） <──> Apps Script
iPhone ショートカット ──> Apps Script（iPhone で読んだページごと送るので Amazon の値段も取れる）
```

- `extract.js` … 商品ページ（JSON-LD・OGP・microdata・Amazon/楽天/ユニクロ専用ルール）から名前・値段・写真を読む。アプリと Apps Script で共通
- `app.js` … 画面、`apps-script/Code.gs` … 保存・取得・値下がりチェック
- スプレッドシート未連携のときは、この端末だけに保存して r.jina.ai 経由で読み取ります

### 取れないことがあるもの

- Amazon で海外発送できない商品は、Google や r.jina.ai（アメリカ）から見ると値段が出ません。iPhone のショートカットから追加すると取れます。値段の自動チェックも同じ理由で取れないことがあります
- ZOZOTOWN などボット対策が強いサイトは読めないことがあります。そのときは「編集」で手入力できます
